# 生成与改稿

用于生成式封面和生成图编辑。纯视频截图、原帧加字按 SKILL.md 处理。

## 图片工具与参考

使用当前运行时的 `imagegen` skill 和原生图片生成/编辑工具，遵循其输入、透明背景、参考图与输出要求。工具不可用时说明限制；不要用程序绘图伪装成生图结果。普通首稿直接沿用已知偏好制作；只有用户要求先选方向，或否定整体风格时，才先给 2—3 个差异明确的方向。

先查看每张本地参考图，再按职责传入：

1. **人物身份图**：用户确认的皮套或本场清晰截图，负责脸、发型、衣服、饰品；修改发型、体型时以用户最新要求为准。
2. **场景内容图**：实际片段截图，负责环境、动作、核心道具、技能和 Logo。必要时多取一帧看清道具，不能只看字幕猜场景。
3. **风格参考图**：用户给定或已有适合的参考，负责信息层级、版式、色彩和字效。没有风格参考也可直接设计，不强制搜索。

人物图优先放前，提示词标明每张图的职责。只保留与笑点或用户要求有关的游戏/聊天证据、品牌图标；清掉无关直播覆盖层、礼物、日期和时钟。多个主播分别锁定身份与数量，避免同一角色重复出现或配错服装。

## 提示词与版本

每次调用前，把完整最终提示词保存到 `prompts/NN-<slug>-<比例>.md`；参考图保存在 `refs/` 并记录来源。提示词写清：

- B 站缩略图用途，视频的梗和实际场景，人物/道具关系；
- 每个人物的身份特征、具体服装、表情、动作、体型关系和准确角色数量；
- 目标比例、构图位置、大脸大字、背景简化及必要留白；
- 本次需要的裁剪安全区，列出须完整保留的字及描边、脸、耳饰、手势、道具；
- 可见文字的逐字内容、换行、主次与颜色；无字版明确无字；
- 参考图各自作用，保留的实际证据/Logo，以及去除的覆盖层。

修改以选定版本为基础，清楚列出本次变化；例如严肃表情、宠溺目光、小辫子、人物高矮或文字大小。不要在改表情时顺便换衣服、脸型或背景。按工具要求传入正确版本的参考图，而不是误用最近一次未采用输出。

把生成输出复制到项目目录并标版本，保留旧稿和原截图。写入 SKILL.md 约定的设计记录；bili-clip 可把交付文件复制到 `clips/<视频 stem>_设计封面_<比例>_vN.png`。

## 制作检查与局部返工

展示前查看原图、所需裁剪图及 320px/160px 缩略图：

- **文字**：逐字正确、换行合理、描边不堵字腔；缩略图主句读得出。
- **身份**：发型、衣服、饰品一致；多个角色没有重复、串脸或错位。
- **动作**：头颈与手臂自然，表情可辨，道具持握和互动关系正确。
- **内容**：背景、道具与视频相关；用户要的广告图标清晰，没有额外人物或多余文字。
- **裁剪**：按 SKILL.md 对应比例检查核心信息和余量。发生碰撞时局部移动或改构图，保住主体和字号，不将整图缩成小岛。

裁剪和缩略图可用本地图像工具生成预览。生成图里的文字错误、身份漂移、姿势问题或裁剪失败，用原生图片编辑/重新生成解决，保存新提示词和版本；不用 Pillow、ImageMagick、Canvas、SVG 或 HTML 在生成图上涂改标题、补边或搬移人物来掩盖问题。

交付与采用按 SKILL.md：制作时完成检查，用户确认后复用该版本；后续发布不重新跑封面检查。
